登录我的 Space

用 GitHub Personal Access Token (PAT) 登录。文章、图片都会写进你自己名下的一个 专属仓库；没有这个仓库时，登录后可以一键创建。

怎么申请 Token？
  1. GitHub → Settings → Developer settings → Personal access tokens
  2. Classic：勾选 repo 权限即可；Fine-grained：对目标仓库给 Contents: Read and write，若要自动建仓再加 Administration: Read and write。
  3. 把 Token 粘贴到上面。它只保存在你本地浏览器，只发往 api.github.com。
Space 设置
这是怎么工作的？
  • 没有后端。整站是静态页面，所有读写都直接走 GitHub REST API。
  • 登录 = PAT。Token 只留在你浏览器里，用于往你的专属仓库提交内容。
  • 数据结构。data/index.json 是清单（Space 信息 + 文章目录），每篇文章是 data/posts/<id>.json，图片放 data/images/。
  • 访客免登录。公开仓库的内容通过 raw.githubusercontent.com 直接读取，访客不需要 Token。
  • 随时可迁移。文章是纯 JSON + Markdown 文本，仓库在你自己手上。
